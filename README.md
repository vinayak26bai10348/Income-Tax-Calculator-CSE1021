# 🇮🇳 Indian Income Tax Calculator

A simple and user-friendly **Python desktop application** that estimates income tax for a salaried individual in India.

The application provides a graphical interface using **Tkinter**, allowing users to enter their gross annual salary and instantly view their taxable income, estimated tax, and salary after tax.

## 📌 About the Project

The **Indian Income Tax Calculator** is a Python-based desktop application developed for educational purposes.

The application uses the **New Tax Regime for FY 2025–26 (AY 2026–27)** and calculates an estimated tax based on the gross annual salary entered by the user.

The calculator performs the following operations:

- Calculates taxable income after standard deduction
- Applies the applicable income tax slabs
- Applies rebate / marginal relief logic implemented in the program
- Adds 4% Health and Education Cess
- Calculates salary remaining after estimated tax
- Displays all major calculation details through a graphical interface

⚠️ **Disclaimer:** This application is intended for academic and learning purposes only. It is not designed for filing an Income Tax Return (ITR) or providing professional tax advice.

## ✨ Features

- 🖥️ **Graphical User Interface** using Tkinter
- 💰 Accepts gross annual salary in Indian Rupees
- 🧮 Automatically calculates taxable income
- 📊 Applies income tax slab calculations
- 🧾 Applies standard deduction of up to ₹75,000
- 🔄 Implements rebate / marginal relief logic
- ➕ Adds 4% Health and Education Cess
- 💵 Displays salary after estimated tax
- ⚠️ Handles invalid input
- 🚫 Handles negative salary values
- 🔘 Simple **Calculate Tax** button
- ❌ Easy **Exit** button
- 📦 No external Python packages required
